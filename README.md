# invest-evo-reports

`invest_evo` 私有运行仓发布的公开研究报告站点。

## 边界

- 本仓只保存经发布闸门校验的静态 HTML/CSS；GitHub Pages 从 `main/docs` 部署。
- 不包含账户、持仓、交易、定投、原始行情、运行日志、密钥或私有运行代码。
- 报告只提供研究证据，不构成投资建议；技术指标不替代资产配置、风险约束或人工判断。
- 历史报告按日期与修订版本保存。修正内容会生成 `daily-rN`，不会静默覆盖旧报告。

## 发布方式

仅由私有 `invest_evo` 的发布作业更新 `docs/`。发布前会执行路径白名单、敏感信息扫描、文件大小与本地链接校验。
